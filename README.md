# 석굴 군주의 옥좌

브라우저에서 돌아가는 5인 파티 자동 던전입니다. 한 층은 **5~7개 선형 블럭**으로 이어지고, 블럭을 클리어할 때마다 **런 한정 강화 3택1**을 고릅니다. 마지막 보스 **고르바크**를 처치하면 장비가 떨어집니다.

이전 빌드(탐험형 랜덤 맵)는 [`VERSIONS.md`](VERSIONS.md)와 `versions/v1/`를 보세요.

## 실행

`석굴 군주의 옥좌.html`을 브라우저에서 엽니다. 빌드·서버 없음.

## 코어 루프

1. 던전 시작 → 블럭 1부터 순서대로 전투
2. 블럭 클리어 → 강화 카드 3장 중 1장 선택 (이번 런만)
3. 보스 블럭 → 고르바크 처치 → 장비 4~5개 드롭 → 클리어
4. 일반/용사 몹은 골드·경험치만. 장비는 보스만

## 폴더

| 파일 | 역할 |
|------|------|
| `석굴 군주의 옥좌.html` | HUD, 캔버스, 전술/기록, 강화 선택 |
| `css/game.css` | 레이아웃·역할색 |
| `js/engine.js` | 블럭 맵, 전투, `AUGMENTS`, 보스 드롭 |
| `js/ui.js` | 저장, pick UI, 그리기 루프 |
| `VERSIONS.md` | 버전·되돌리기 |
| `versions/v1/` | 이전 코어 루프 스냅샷 |

## 첫 수정 지점

- 밸런스: `js/engine.js`의 `TUNE`
- 강화 풀: `AUGMENTS` (18종)
- 블럭 수: `createGame`의 `5 + rnd(3)`
